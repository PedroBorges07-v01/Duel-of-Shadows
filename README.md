# Duel of Shadows

## Sobre o projeto

Duel of Shadows é um jogo 2D de combate em arena desenvolvido na Unity, no qual o jogador enfrenta sombras capazes de reproduzir seus movimentos e ações anteriores.

## Mecânica principal

- O jogador possui 10 segundos para executar ações livremente pela arena.
- Durante esse período, seus comandos de movimentação e pulo são registrados.
- Ao término da rodada, uma sombra é criada na posição espelhada do jogador.
- A sombra reproduz os comandos registrados, respeitando suas próprias condições físicas.
- O jogador precisa utilizar essa mecânica estrategicamente para enfrentar seus oponentes.

## Tecnologias utilizadas

- Unity
- C#
- Unity Input System
- Cinemachine

## Como executar

1. Clone este repositório.
2. Abra o Unity Hub.
3. Selecione a opção de adicionar projeto existente.
4. Selecione a pasta `DuelOfShadows`.
5. Abra a cena principal localizada em `Assets/Scenes`.
6. Execute o jogo pelo botão Play da Unity.
